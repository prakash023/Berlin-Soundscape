\# Berlin Soundscape



An interactive sound map of Berlin created for #30DayMapChallenge 2026-Day 11: Senses · Sound.



The map visualizes cultural venues across Berlin and turns them into an interactive soundscape:



\- 🟣 Nightclubs — electronic / faster pulse

\- 🟠 Live Music — medium / varied pulse

\- 🔵 Theatre — slower / atmospheric pulse



Built with QGIS, Python, MapLibre GL JS and Web Audio API, using real OpenStreetMap venue data.
